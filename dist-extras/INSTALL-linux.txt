OPENSET {{VERSION}} - INSTALLAZIONE SU LINUX
================================
Guida completa con le novita': OpenSet-{{VERSION}}-Guida.pdf

1. Scarica ed estrai lo zip:
     unzip openset-{{VERSION}}-linux-x64.zip -d openset && cd openset

2. Rendi eseguibile e avvia il server (il browser si apre da solo):
     chmod +x openset-{{VERSION}}
     ./openset-{{VERSION}}
   Senza aprire il browser:  ./openset-{{VERSION}} --no-open

3. Indirizzo: su Linux la porta 80 richiede root, quindi OpenSet usa la
   39080: http://localhost:39080 su questo PC, http://<ip>:39080 dal
   telefono sulla stessa rete. In Opzioni -> Connetti un dispositivo c'e'
   il QR code da inquadrare con il telefono.

NOTA: Ableton Live non esiste per Linux. Usa Linux come postazione di
controllo/visualizzazione remota, oppure carica un progetto offline:
     ./openset-{{VERSION}} "/percorso/Progetto Project/Progetto.als"

Per il Remote Script (sul computer Win/Mac con Live) vedi il README: su
Windows e macOS OpenSet lo installa da solo.

Dati (scaletta, testi, custom.css): ~/.config/openset
(o $XDG_CONFIG_HOME/openset). Al primo avvio OpenSet copia li' i file che
le versioni precedenti tenevano accanto al programma.

Se compare "OpenSet cannot start ... already running": OpenSet e' gia'
aperto (o AbleSet, che usa la stessa porta 39051). Chiudi l'altra istanza.
