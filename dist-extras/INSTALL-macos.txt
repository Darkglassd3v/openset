OPENSET - INSTALLAZIONE SU MACOS
================================

1. Scarica ed estrai lo zip giusto per il tuo Mac:
     Apple Silicon (M1-M4):  unzip openset-macos-arm64.zip -d openset && cd openset
     Mac Intel:              unzip openset-macos-x64.zip -d openset && cd openset

2. Rimuovi la quarantena e avvia (binario con firma ad-hoc, non notarizzato):
     chmod +x openset
     xattr -d com.apple.quarantine openset 2>/dev/null || true
     ./openset
   Se macOS chiede di accettare connessioni in entrata, consenti: serve
   per telefono/tablet e per i controller OSC.

3. Installa il Remote Script in Ableton Live 12:
   - Copia la cartella  remote-script/OpenSet  in:
     ~/Music/Ableton/User Library/Remote Scripts/
     (crea "Remote Scripts" se non esiste)
   - Riavvia Live -> Live -> Impostazioni -> Link/Tempo/MIDI ->
     Superficie di controllo -> OpenSet (Input/Output: Nessuno)

4. Apri nel browser l'indirizzo mostrato nel terminale
   (http://localhost:39080 sul Mac, http://<nome-mac>.local:39080 dal
   telefono sulla stessa rete Wi-Fi).

5. iPad/iPhone come app: in Safari apri http://<nome-mac>.local:39080,
   poi Condividi -> Aggiungi alla schermata Home. Per lo schermo sempre
   acceso: Impostazioni -> Schermo e luminosita' -> Blocco automatico -> Mai.

Progetto offline senza Live:
     ./openset "/percorso/Progetto Project/Progetto.als"

Se compare "OpenSet cannot start ... already running": OpenSet e' gia'
aperto (o AbleSet, che usa la stessa porta 39051). Chiudi l'altra istanza.
