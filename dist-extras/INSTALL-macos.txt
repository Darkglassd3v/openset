OPENSET {{VERSION}} - INSTALLAZIONE SU MACOS
================================
Guida completa con le novita': OpenSet-{{VERSION}}-Guida.pdf

1. Scarica ed estrai lo zip giusto per il tuo Mac:
     Apple Silicon (M1-M4):  unzip openset-{{VERSION}}-macos-arm64.zip -d openset && cd openset
     Mac Intel:              unzip openset-{{VERSION}}-macos-x64.zip -d openset && cd openset

2. Rimuovi la quarantena e avvia (binario con firma ad-hoc, non notarizzato):
     chmod +x openset-{{VERSION}}
     xattr -d com.apple.quarantine openset-{{VERSION}} 2>/dev/null || true
     ./openset-{{VERSION}}
   Il browser si apre da solo (senza: ./openset-{{VERSION}} --no-open).
   Se macOS chiede di accettare connessioni in entrata, consenti: serve
   per telefono/tablet e per i controller OSC.

3. Remote Script: OpenSet lo copia da solo in
     ~/Music/Ableton/User Library/Remote Scripts/OpenSet
   Poi riavvia Live -> Impostazioni -> Link, Tempo e MIDI ->
   Superficie di controllo -> OpenSet (Input/Output: Nessuno).
   Se hai spostato la User Library, copia a mano la cartella
   remote-script/OpenSet nella sua cartella "Remote Scripts".

4. Indirizzo: OpenSet usa la porta 80 se e' libera, altrimenti la 39080.
   Sul Mac: http://localhost . Da telefono e tablet sulla stessa rete:
   http://<nome-mac>.local (resta valido anche se cambia l'IP), oppure
   inquadra il QR code in Opzioni -> Connetti un dispositivo.
   Per forzare una porta:  PORT=39080 ./openset-{{VERSION}}

5. iPad/iPhone come app: apri l'indirizzo in Safari, poi Condividi ->
   Aggiungi alla schermata Home. Per lo schermo sempre acceso:
   Impostazioni -> Schermo e luminosita' -> Blocco automatico -> Mai.
   Se avevi aggiunto l'icona con la 0.3.x (indirizzo con :39080),
   aggiungila di nuovo.

Dati (scaletta, testi, custom.css): ~/Library/Application Support/OpenSet
Al primo avvio OpenSet copia li' i file che le versioni precedenti
tenevano accanto al programma (gli originali restano dove sono).

Progetto offline senza Live:
     ./openset-{{VERSION}} "/percorso/Progetto Project/Progetto.als"

Se compare "OpenSet cannot start ... already running": OpenSet e' gia'
aperto (o AbleSet, che usa la stessa porta 39051). Chiudi l'altra istanza.
