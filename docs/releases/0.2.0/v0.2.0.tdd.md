## Percorsi utente

1. Come musicista voglio che a fine brano lo show passi al brano successivo della
   *mia* scaletta, o si fermi, senza toccare Live.
2. Come band voglio riordinare, saltare e annotare i brani dal telefono, e
   salvare più scalette, senza modificare il set di Live.
3. Come cantante voglio testi e accordi a tempo, trasposti per brano.
4. Come direttore musicale voglio comandare tutto da tastiera, pedale, MIDI,
   TouchOSC o Stream Deck (OSC compatibile AbleSet, HTTP).
5. Come utente Windows o Mac (anche Apple Silicon) voglio un eseguibile che
   funzioni e messaggi chiari quando qualcosa non va.
6. Come utente senza Live voglio vedere la scaletta da un file `.als`.

## Lacune note

- Nessun test automatico con Ableton Live reale: l'API di Live è simulata.
  Da provare su Live: `Song.clip_trigger_quantization` impostata con l'enum di
  Live, `Track.arrangement_clips` (Live 11+), salto quantizzato di `CuePoint.jump()`.
- UI verificata a mano nel browser, senza test end-to-end automatici.
- MIDI via Web MIDI: solo Chrome/Edge su localhost; una sola scheda aperta.
- Rami non coperti: log difensivi nei `catch`, fallback del vecchio framework
  `_Framework`, ioctl di Windows (eseguito dalla CI Windows).
