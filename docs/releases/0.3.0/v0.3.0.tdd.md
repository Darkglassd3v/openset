copertura con `npm run coverage`.

## Percorsi utente

1. Come band senza Live aperto voglio sezioni e testi dalle tracce `Sections` e
   `+LYRICS` del file `.als`.
2. Come direttore musicale voglio durate e tempi rimanenti giusti anche quando
   il tempo cambia nel brano.
3. Come musicista voglio sentire in cuffia il nome della sezione in arrivo e un
   count-in.
4. Come band voglio un secondo computer di riserva che segue i comandi del primo.
5. Come cantante voglio vedere sul mio tablet solo quello che mi serve, testo compreso.
